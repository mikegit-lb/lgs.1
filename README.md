# LGS

Study material and tools for LGS (Turkish 8th-grade national exam) preparation.

The first project is **`lgs-english/`**, an offline English practice app (Lesson 1: study, practice and a timed
10-question mini exam). See [`lgs-english/README.md`](lgs-english/README.md) for how to run it, and the
implementation plan in [`docs/superpowers/plans/2026-10-08-lgs-english-lesson1.md`](docs/superpowers/plans/2026-10-08-lgs-english-lesson1.md).
